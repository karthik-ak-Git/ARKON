# ARKON Desktop

Desktop application built with Electron.

## Prerequisites

- Node.js 18+
- npm

## Setup

```bash
# Install desktop dependencies
cd desktop
npm install
```

## Development

```bash
# Run in development mode (starts frontend + Electron)
npm run dev
```

## Build

```bash
# Build for Windows
npm run build:win

# Build for macOS
npm run build:mac

# Build for Linux
npm run build:linux
```

Output will be in `desktop/release/`.
