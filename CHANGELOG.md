# Changelog

All notable changes to ARKON will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2026-08-07

### Added
- Multi-agent runtime with sandboxed execution
- Workflow engine with DAG-based orchestration
- Execution engine with dependency resolution and retry
- AI gateway supporting 7 providers (OpenRouter, Gemini, Ollama, NVIDIA NIM, Copilot, Gemini CLI, OpenCode)
- Plugin system with lifecycle management and marketplace
- Resource manager with CPU, memory, disk, and GPU monitoring
- Scheduler with priority, fairness, and preemption
- Event bus with pub-sub and dead-letter queues
- Workspace runtime with snapshots and state persistence
- Tauri desktop application with React frontend
- 59 REST endpoints and 2 WebSocket endpoints
- 1,200+ automated tests
- NSIS Windows installer
- Portable version support
