# ARKON Portable

This directory contains the portable version of ARKON.

## Usage

1. Extract `ARKON-Portable.zip` to any folder
2. Run `ARKON-Desktop\arkon-desktop.exe`

No installation required. All configuration is stored in the extraction directory.

## Building

```bash
# From project root
scripts\package-portable.bat
```

Output: `dist/ARKON-Portable.zip`
