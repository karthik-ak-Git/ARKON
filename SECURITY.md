# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT** open a public GitHub issue
2. Email security details to the maintainer
3. Include description, steps to reproduce, and impact
4. Allow reasonable time for a fix before public disclosure

## Security Best Practices

- ARKON runs locally — no data is sent to external servers unless you configure a cloud AI provider
- Plugin execution is sandboxed
- API keys are stored locally in your config directory
- No telemetry is collected by default
